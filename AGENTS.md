# Project Guidelines & Rules

## 📦 Release Management
- **Никогда не создавать релизы и теги на GitHub автоматически.**
- Создавать релизы на GitHub (`gh release create`, `git tag`) **исключительно** по явной просьбе пользователя в запросе (например: «Сделай релиз...»).
- При создании релиза прикреплять скомпилированный архив приложения (`MyDay-vX.Y.Z-macOS.zip`) и подробные Release Notes.

## 🚀 Git & Workflow
- **Всегда пушить сделанные коммиты в Git (`git push origin <branch>`)** после успешного внесения, тестирования и коммита изменений.
